# Market News: image prompts

Each prompt below is complete: the shared style is already included, so copy
one code block into the image generator as it is.

Save the results in `assets/images/market-news/` under the file name given,
as WebP at the size given, ideally under ~150 KB each.

## 4. Calendar category icons (256 × 256, transparent)

as one set so they match, then cut them into five files:
`icon-central-banks.png`, `icon-speeches.png`, `icon-data.png`,
`icon-earnings.png`, `icon-commodities.png`.

```
A set of five minimal line icons in a row, gold strokes (#F0B429) on a transparent background, consistent 2px stroke weight, rounded caps and joins, same size and visual weight, flat, no fill, no text: (1) a classical bank building with columns, (2) a microphone on a stand, (3) a bar chart with an upward trend arrow, (4) a document with a percent sign, (5) an oil barrel next to an ear of wheat. Each icon centered in its own square, 256x256 per icon.
```
