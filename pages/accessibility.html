Accessibility Statement

Web Accessibility Act (WZG) and EU Directive 2016/2102

Black Quant Empire endeavours to make its website accessible in accordance with the Web Accessibility Act (WZG) implementing Directive (EU) 2016/2102.

This accessibility statement applies to the website: https://www.blackquantempire.trade

Legal basis: Web Accessibility Act (WZG)

Status of Compliance with the Requirements

This website is largely compliant with conformance level AA of the “Web Content Accessibility Guidelines – WCAG 2.2” and with the applicable European standard EN 301 549 V3.2.1 (2021-03) and the Austrian Web Accessibility Act (WZG).

Below you will find an overview of the areas in which the website meets the standards, as well as the known limitations.

Accessible Features and Conformance

The website comprehensively implements the following accessibility features:

Navigation and Structure

Skip links for bypassing the navigation at the top of the page. Correct use of landmark elements (header, nav, main, article, footer). Logical structure from h1 to h3 on all pages. ARIA attributes (aria-expanded, aria-current, aria-hidden) used correctly. Responsive navigation menu with keyboard control (Escape key).

Colours and Contrast

All text elements meet the contrast ratio of at least 4.5:1 for normal text (colour contrast AA). Information is not conveyed by colour alone. Clearly recognisable focus states for keyboard use.

Images and Media

All meaningful images have descriptive alt text. Decorative images are marked with aria-hidden="true". Embedded videos are provided with English subtitles.

Forms and Input

All form fields have meaningful labels. Clear error messages and validation hints. All interactive elements can be operated via the keyboard (Tab, Enter, Escape).

Responsive Design

The website works on devices from 320px up to 4K (mobile-first design). The layout remains legible at up to 200% zoom. Users can change the font size in the browser.

Non-Accessible Content

The content listed below is not fully accessible for the following reasons, or has known limitations:

a) Responsive design at extreme zoom levels

Zoom levels above 200%: At very high zoom levels (above 200%), display errors and unexpected line breaks can occur. The website has been optimised for standard zoom levels (100-200%). This corresponds to common practice in web design.

b) Decorative background images on mobile devices

Fixed-position background images: The "About Us" page (about.html) uses decorative background images with background-attachment: fixed. On mobile devices this is changed to background-attachment: scroll in order to avoid performance problems. This can lead to visual differences between desktop and mobile devices, but does not impair the accessibility of the content.

c) Decorative images in the page layout

Trend chart images: Several pages (Careers, License) contain decorative trend chart images at the sides of the content. These are hidden on mobile devices in order to save space and improve legibility. They do not contribute to the understanding of the page content and are correctly marked as decorative (alt="" aria-hidden="true").

d) Disproportionate burden

At the present time, no content is known that would constitute a disproportionate burden. Should this change, we will update this statement.

e) Our commitment

We are constantly endeavouring to improve the accessibility of our website. If you encounter barriers or problems, please let us know (see the contact details below). We will review your request and take measures to resolve the problem.

Audit methodology

The assessment of the website's compliance with the Web Accessibility Act (WZG) implementing the requirements of Directive (EU) 2016/2102 was carried out by means of:

Automated tests with WAVE (WebAIM Accessibility Evaluation Tool) to detect common accessibility problems. Manual review of keyboard navigation on all pages (Tab, Enter, Escape, arrow keys). Screen reader testing to verify with screen readers (semantic HTML, ARIA labels). Responsive design tests on mobile devices (375px, 768px, 1024px breakpoints). Zoom tests for layout stability at 100%, 150% and 200% zoom. Colour contrast review for WCAG AA contrast ratios (4.5:1 for normal text).

Enforcement Procedure

If the responses from the contact option named above are unsatisfactory, you can lodge a complaint with the Austrian Research Promotion Agency (Österreichische Forschungsförderungsgesellschaft mbH, FFG).

The FFG accepts complaints electronically via a contact form.

The FFG examines complaints as to whether they relate to infringements of the requirements of the Web Accessibility Act, in particular shortcomings in compliance with the accessibility requirements, by the federal government or an institution attributable to it.

If the complaint is justified, the FFG must issue recommendations for action to the federal government or the legal entities concerned and propose measures that serve to remedy the shortcomings at hand.
